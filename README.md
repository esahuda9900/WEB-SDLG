# Web Warranty Claim SDLG

Web monitoring dan submit klaim warranty SDLG untuk admin dealer.

- **Stack:** React + Vite + TypeScript, Supabase, GitHub Pages
- **Base path:** `/WEB-SDLG/`
- **Router:** HashRouter (aman untuk GitHub Pages)
- **Bahasa:** Indonesia

## Pengembangan lokal

```bash
npm install
npm run dev
```

## Deploy

Push ke `main` → GitHub Actions membangun dan deploy ke GitHub Pages.

URL produksi (setelah Pages diaktifkan): `https://esahuda9900.github.io/WEB-SDLG/`

## Milestone

Lihat `STATUS.md` dan `AGENTS.md`.
