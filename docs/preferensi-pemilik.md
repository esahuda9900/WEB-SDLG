## Tampilan halaman detail klaim (2026-10-30)

- **Tidak suka** layout padat seperti sistem referensi (semua data selalu terbuka, banyak section setingkat, scroll panjang, evidence grid kosong).
- **Suka** layout 2 kolom (kiri utama, kanan ringkas + total menonjol).
- **Suka** section yang bisa ditutup/buka (Collapsible), bukan tab.
- State buka/tutup disimpan di localStorage supaya sistem ingat preferensi admin.
- Default terbuka: Deskripsi kerusakan & analisis, Parts & biaya detail.
- Default tertutup: Metode perbaikan & teknisi, Catatan status / SDLG.
- Visual distinction jelas antara state tertutup vs terbuka di dark theme (background berbeda tipis).
